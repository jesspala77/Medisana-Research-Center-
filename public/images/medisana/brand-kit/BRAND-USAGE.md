## Usage Notes

- Use the full logo for headers, proposals, CVs, presentations, and formal documents.
- Use the compact mark for favicons, social avatars, Microsoft tenant/profile icons, and small UI placements.
- Avoid using the full text logo at favicon sizes because the wording becomes unreadable.
