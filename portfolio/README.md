# Portfolio Structure

This folder is a working structure for portfolio development while SynNexus intake is producing leads.

## Folders

- `case-studies/` long-form client stories and outcomes
- `services/` one-pagers for offerings
- `projects/` project snapshots and media
- `assets/images/` raw and optimized image files
- `assets/docs/` PDFs, capability decks, certifications
- `templates/` reusable markdown/page templates
- `drafts/` work-in-progress content

## Suggested workflow

1. Draft in `drafts/`
2. Promote to `projects/` or `case-studies/`
3. Reuse structures from `templates/`
4. Keep source files in `assets/`
